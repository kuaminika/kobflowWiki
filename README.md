# Kobflow Wiki

Kobflow is a money management app for tracking the flow of money 
across accounts — expenses, incomes, and the "kobholders" (accounts/
wallets) they move through.

This repo is documentation only. It has no code.

## Where to look

- New here? Start with [components.md](./components.md) to see high level components 
- You can check the repos [here](./repos.md)
- Understanding the domain? See [domain/entities.md](./domain/entities.md)
- Working on the frontend rebuild? See [architecture/](./architecture/)
- Setting up your dev environment? See [setup/](./setup/)
